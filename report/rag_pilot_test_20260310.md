---

## 테스트 목적

VOD 메타데이터(smry, director, series_nm)의 결측치를 TMDB API로 자동 보강하는 RAG 파이프라인 검증

---

## 파이프라인 구성

```
vods 결측 조회
    ↓
TMDB API 검색 (1순위)
    ├─ 검색 전 clean_title() 적용 → 에피소드 번호 제거
    │    예) "사랑의 이름으로 01회" → "사랑의 이름으로"
    └─ 결과 있으면 DB 업데이트
    ↓
Ollama LLM 폴백 (2순위) ← 이번 테스트는 --tmdb-only로 비활성화
```
